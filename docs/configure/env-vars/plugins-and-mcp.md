These variables change how Claude Code loads plugins, runs MCP servers, finds skills, and runs hooks. They set time limits, token limits, cache paths, and marketplace behavior.

Use them to tune slow MCP servers or to lock down plugin loading. To set one, add it to the `env` key of a settings file, as the example shows, or export it before you start `claude`.

This page lists 115 variables. `MCP_TIMEOUT` and `MCP_TOOL_TIMEOUT` are common. Switch rows take `1`.

## Example

```json title="~/.claude/settings.json"
{
  "$schema": "https://clawdipedia.cc/schemas/claude-code-settings.json",
  "env": {
    "MCP_TIMEOUT": "30000",
    "MCP_TOOL_TIMEOUT": "120000"
  }
}
```

A server gets 30 seconds to start, and a tool call gets two minutes.

## How It Works

Plugins and MCP servers start when a session starts. Claude Code reads these variables early.
Claude Code passes some variables to MCP server and hook processes. It can strip credentials first when `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` is on.
